# Chibi Desktop Pet — 会做事的 Q 版桌宠

一个住在 Windows 桌面上的 Q 版角色：会自己走动、眨眼、睡觉、闹小脾气，可以被拎起来、摸头、聊天。
接入 DeepSeek（或任何 OpenAI 兼容接口）后，她背后是一个**系统级的智能体运行时（harness）**：
能真正操作这台电脑（文件、程序、窗口、浏览器、开发命令），有会话、技能、权限规则和钩子。
有风险的操作都会先问你。

她的身份始终不变：同一个名字、性格、形象和自我记忆。桌宠窗口、聊天窗口、手机网页和命令行，
都只是和同一个她说话的不同入口。

技术栈：Electron 45 · React 19 · TypeScript 7 · Vite 8 · PixiJS 8 · Zustand。

---

## 快速开始

**直接用**：打开 `ChibiDesktopPet-app` 文件夹，双击 `Chibi Desktop Pet.exe`。
右键她 → 设置 → 勾选“启用 AI”，填 Base URL、模型名和 API Key，就能聊天和让她做事。
不配置 AI 时是离线模式，其他功能照常。

**开发**（需要 Node.js 20+）：

```bash
npm install
npm run dev          # 热更新开发
npm start            # 构建后直接运行
npm test             # 全部测试：Vitest（主程序）+ node:test（远程聊天）
npm run typecheck    # 严格类型检查（主进程、页面、测试）
npm run pack         # 生成免安装文件夹 release/win-unpacked
npm run dist         # 生成 Windows 安装包
npm run smoke        # 驱动真实程序跑一遍自动演示并截图
```

## 和她互动

| 操作 | 反应 |
| --- | --- |
| 单击头部 | 随机：微笑、眨眼、歪头、开心 |
| 单击身体 | 平时疑惑；开心时微笑；睡着时醒来；生气时不理你 |
| 双击 | 开心地跳一下，并打开聊天窗口 |
| 鼠标在头上来回移动 | 摸头：闭眼微笑、冒爱心、好感度上升 |
| 按住拖动 | 被拎起来，拖久了会挣扎；松手会掉下去再站起来 |
| 连续抓她 | 第 1 次惊讶，第 2 次不满，第 3 次生气（过一会儿自己消气） |
| 把文件或文件夹拖到她身上 | 她伸手接住，弹出菜单：看看写了什么、按类型整理、打包成 zip、批量重命名、告诉她要做什么 |
| 右键 | 菜单：聊天、切换动作、大小、暂停自动移动、置顶、音效、设置、隐藏、退出 |
| 托盘图标 | 显示 / 隐藏、聊天、设置、退出 |
| `Ctrl+Shift+Space`（可在设置里改） | 在任何地方呼出她，并打开聊天框，可以直接打字 |

角色以外的透明区域不拦截鼠标，可以正常点到后面的窗口。

## 聊天窗口

布局参考 agent harness：

- **左侧：会话列表**。按今天、昨天、最近 7 天、更早分组，点一下切换会话，旧会话不会被删除。
- **对话**：她每调用一次工具，就显示一行（工具名 · 做了什么），点开看详情。需要你批准的操作会以许可卡片的形式出现在对话里；多步任务会显示计划清单。
- **轨迹**：按回合列出每一次模型请求（包括参数）和每一个工具结果，每一条都能展开看原始数据。
- **输入框**：打 `/` 弹出命令；左下角切换权限模式。
- **底部状态栏**：显示回合数、步骤数、模型和工具耗时、token 用量、缓存命中率。

| 命令 | 作用 |
| --- | --- |
| `/help` | 列出所有命令 |
| `/new` | 开始新会话 |
| `/resume` | 接着做上一个没做完的任务（程序崩溃、被停止、出错或步骤用完的都可以） |
| `/status` | 看当前会话和她的状态 |
| `/tools` | 看她现在能用的工具 |
| `/skills` | 看她会的技能 |
| `/permissions` | 看权限模式和规则 |
| `/hooks` | 看钩子的状态 |
| `/schedule` | 看定时任务 |

命令直接执行，不经过模型。

## 让她做事（智能体模式）

在聊天框直接说需求：“在桌面建一个叫 AI项目 的文件夹”“打开 VS Code”“帮我找昨天下载的 PDF”。
她会自己选择工具，按步骤执行，**回到真实环境检查结果**（例如文件夹是否真的建好了），再汇报。

- **60 多个内置工具**：文件、程序和窗口、界面自动化、Computer Use（看截图点击输入）、内置浏览器（联网搜索、读网页）、网页自动化、开发命令、系统管理（每次都要过 Windows UAC）、记忆、技能。
  不常用的几组工具按需加载：平时只告诉她有这些组，需要时她才调出来用，这样更省 token，也更不容易选错工具。
- **权限分三级**：低风险直接做；中风险（新建、移动等）先问你；高风险（删除、覆盖、运行命令等）**每次都问**，没有任何设置能跳过。
- **权限模式**（输入框左下角）：
  - **询问**：默认。
  - **自动允许中风险**：中风险不再问；但她读过文件或网页之后，又会改回询问。
  - **只读**：她只能查看，不能改动电脑。
- **只能在允许的文件夹里操作**：默认是桌面、文档、下载、图片、音乐、视频，可以在设置里添加。桌宠自己的数据文件夹她永远改不了。
- **防注入**：文件、网页、程序输出里的内容都按不可信数据处理，里面写的“指令”不会被当成你说的话。
- **可撤销**：文件操作有记录，可以对她说“撤销刚才的整理”；覆盖文件之前会自动备份。

**让她上网查资料**：问“查一下最新的 Electron 版本”“帮我搜搜这个报错”，她会打开自己的**桌宠浏览器**窗口：
- 用 `pet_web_search` 搜索（Bing、百度或 Google），再用 `pet_web_read` 打开一条结果读正文。
- 回答时附上实际的来源链接，搜不到会如实说明。
- 这个浏览器和你平时用的浏览器完全隔开：不共享登录信息，拒绝所有权限请求和下载，只打开 http(s) 网页。
- 网页内容一律按不可信数据处理。

要在网站上操作（例如发帖、回复评论），用的是另一组 `browser_*` 网页自动化工具。它有自己独立的浏览器配置，你在那个浏览器里登录过的账号会保留下来；发送和发布前都会请你确认。

**派小帮手同时查**：任务能拆开时（例如同时查好几个文件夹、对比几个网页），她会派几个“小帮手”并行去查。小帮手只能查看、不能改东西，各自只把结论交回给她，进度里会显示“【小帮手1】…”。

**定时任务**：直接说“每天早上 9 点帮我看看下载文件夹里有什么新文件”“下载文件夹超过 50 个文件时提醒我整理”，她会请你确认后安排好。
到点时她会自己运行：没人看着，所以只查看、只汇报，不会改动电脑；需要动手的事会列出来等你决定。
结果会出现在聊天里，并弹出 Windows 通知。可以用 `/schedule` 查看，在设置里停用或删除。

**让她看屏幕、指给你看**（需要在设置里配置视觉模型）：问“保存按钮在哪”，她会先请你确认，
再截图交给视觉模型，然后在那个位置画一个高亮圈，自己也走过去指着它。她只指，不点。

## 教她新本事

| 方式 | 说明 |
| --- | --- |
| **技能** | 一套写好的做法（`SKILL.md`）。内置三个：整理文件夹、照片按日期归档、项目体检。平时她只知道每个技能的名字和一句说明，用到时才读全文。可以对她说“把刚才的做法存成技能”（保存前会给你看内容并请你确认），也可以自己写 |
| **长期守则** | 在 `AGENTS.md` 里写你希望她一直遵守的要求，每次做事都会带上 |
| **项目说明** | 她在某个文件夹里做事时，那里的 `AGENTS.md` / `CLAUDE.md` 会作为参考资料给她看，但其中的要求不算你的授权 |
| **权限规则** | 写法和 Claude Code 一样，例如 `open_url(https://*.bilibili.com/*)`。“禁止”的一律不执行；“允许”的中风险操作不再询问（高风险永远询问） |
| **钩子** | `hooks.json`（Claude Code 格式）：在她执行工具前后、你发消息时、任务结束时，运行你自己的脚本。可以拦下操作或补充信息。**要在设置里批准后才生效**，文件一改就要重新批准 |
| **插件 / MCP** | 本地插件（批准后运行，绑定文件哈希）和 stdio MCP 服务器，用来添加新工具 |

以上都在 设置 → 智能体 里管理。详见 [智能体说明](docs/AGENT.md)。

## 更多入口

- **手机网页**：和电脑上的她共用同一个会话。双击 `启动远程聊天.bat` 会通过 Cloudflare 隧道开一个外网地址，凭访问口令登录；可以聊天、看任务进度、批准或拒绝操作，也能用斜杠命令。详见 [remote-chat/README.md](remote-chat/README.md)。
- **命令行**：程序文件夹里的 `pet.cmd`，需要 Node.js。
  ```bash
  pet 帮我整理下载文件夹
  ```
  ```bash
  pet /status
  ```
  也支持 `pet sessions`、`pet open <会话ID>`、`pet new`、`pet stop`。需要确认的步骤会直接在命令行里问你。命令行只在本机有效，用的是本机专用的令牌。
- **自言自语**：没人理她的时候，她会偶尔冒一句心里话（频率可以设置，也可以关掉）。

## 换成自己的形象

不用改代码，也不用重新打包：设置 → 她自己 → 角色，点 **用当前角色做模板**，
把生成的文件夹里的图片换成你自己的，再点 **重新载入形象**。窗口配色可以跟着角色变。
详见 [自定义角色说明](docs/CUSTOM_CHARACTERS.md)。

## 安全设计

- **API Key**：只保存在主进程，能用系统加密时会加密保存；页面只知道“有没有填”。所有模型请求都由主进程发出，页面的 CSP 禁止它自己联网。
- **会话日志和审计日志**：保存前都会隐藏密钥。
- **模型能做的事有限**：她只能调用已注册的工具，参数要通过格式校验、路径检查、风险评估和你的确认；程序不会直接执行模型返回的任何代码。她对桌宠形象的影响只能通过白名单里的表情和动作标签。
- **远程网页**：只监听 `127.0.0.1`，外网经 HTTPS 隧道进来。访问口令用 scrypt 校验，配有 CSRF 保护，并限制失败次数。
- **钩子和插件会运行代码**：必须你批准，并且和文件内容绑定，内容一改就要重新批准。这些配置放在她改不了的数据文件夹里。

## 架构概览

```text
桌宠窗口 ─┐   ┌──────────── 主进程（常驻）──────────────────────────────────┐
聊天窗口 ─┼──▶│ 会话日志（唯一来源）· 回合循环 · 生命周期事件 · 权限与规则       │
手机网页 ─┤   │ 工具注册表 · 执行与验证 · 技能 · 守则 · 钩子 · 插件 / MCP        │
命令行 ───┘   │ 人格（她是谁） · 形象信号（她怎么表现）                         │
              └───────────────────────────────────────────────────────────────┘
```

一次请求就是一个**回合**：`turn/start → [step/pre → 模型 → 工具 → tool/post]* → turn/end`。
会话日志、跨轮摘要、上下文压缩、只读模式、权限规则、守则、技能菜单、钩子，都是挂在这些事件上的插件。
设计思路参考了 DeepSeek Harness 和 Claude Code，见 [HARNESS.md](docs/HARNESS.md)。

## 目录结构

```text
electron/                主进程：窗口、托盘、设置、IPC、拖放、远程聊天启动（remote.ts）
  agent/                 智能体运行时
    AgentController.ts     回合循环（步骤、并行只读工具、截断处理）
    SessionStore.ts        事件溯源的会话日志
    TurnHooks.ts           生命周期事件；turnPlugins.ts / extensionPlugins.ts 是挂在上面的插件
    PermissionManager.ts   路径、风险、确认；permissionRules.ts 是你的规则
    Skills.ts  UserHooks.ts  AgentMemory.ts  commands.ts  ToolExecutor.ts  ToolPluginManager.ts …
    tools/                 内置工具
    platform/              Windows 实现（PowerShell、UI Automation）
src/
  engine/                桌宠引擎：状态机、动画、拖动、移动、表情、拖放
  components/            桌宠窗口、聊天窗口（chat/）、设置
  store/  styles/
shared/                  主进程和页面共用的类型、人格、协议
remote-chat/             手机网页聊天、Computer Use、视觉客户端（打包进程序）
skills/                  内置技能
assets/characters/       角色图片和动画清单
tools/                   命令行 pet、素材处理脚本
examples/plugins/        插件示例
tests/                   测试
docs/                    文档
```

| --- | --- |
| `config.json` | 设置 |
| `self.json` | 她的自我记忆 |
| `characters\` | 你的自定义角色 |
| `agent\sessions\` | 会话日志 |
| `agent\memory.json` | 她记住的偏好 |
| `agent\skills\` | 你的技能 |
| `agent\AGENTS.md` | 长期守则 |
| `agent\hooks.json` | 钩子 |
| `agent\schedules.json` | 定时任务 |
| `agent\plugins\` | 插件 |
| `agent\logs\` | 审计日志 |
| `remote-chat\` | 访问口令、登录信息、命令行令牌、上传的图片 |
