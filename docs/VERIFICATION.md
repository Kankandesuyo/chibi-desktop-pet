## 与原始需求的差异

- 任务计划由模型通过 `update_plan` 工具自己写，而不是单独的规划模型调用：少一次请求，也适用于任何需求。
- 浏览器自动化使用桌宠专用的浏览器配置，不读取你自己浏览器的登录状态（安全考虑）。需要登录的网站要在那个窗口里自己登录一次。
- UI 自动化优先使用无障碍接口；控件不支持时，只有显式开启 `allowMouseFallback`（高风险）才会按控件位置点击，从不按任意坐标点击。目前这个开关没有暴露给模型。
- 插件以完全信任的代码运行（与 VS Code 扩展类似），安全保证来自“批准 + 哈希绑定 + 工具最低中风险”，不是沙箱。
- 没有生成 Windows 安装包，只有免安装文件夹。
