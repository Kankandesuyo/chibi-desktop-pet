# 桌宠远程聊天

用手机浏览器和电脑上的同一个桌宠 Agent 对话。复用现有角色图片、橙色与奶油色聊天界面、人格、Agent 记忆、工具和权限检查。桌面和网页共用一份会话，消息、回复、任务进度、停止和确认卡会双向同步。

## 使用

1. 双击项目根目录 `启动远程聊天.bat`，会打开网页并生成 `远程聊天地址.txt`。
2. 访问口令在 `%APPDATA%\chibi-desktop-pet\remote-chat\访问口令.txt`。
3. 在手机上打开外网地址、输入访问口令。可以聊天、查看任务进度、允许或拒绝操作、停止当前共享任务。点击右上角“设置”可调整人格、外观、模型与智能体模式；保存会同步到电脑端。确认等待约两分钟会自动拒绝；需要 Windows UAC 的步骤仍需在电脑前处理。
4. 电脑需保持开机、联网，桌宠和隧道需运行。双击 `关闭远程聊天.bat` 关闭外网入口。该操作不会中断已发出的任务；先在网页点“停止任务”可以取消任务。

当前采用 Cloudflare Quick Tunnel。临时地址在隧道重启后会变化，无运行时长保证；地址见项目根目录文本。长期固定网址需要具备域名和命名 Tunnel 配置。没有自动更改电脑休眠、电源或开机启动设置。

## 结构（面向初学者）

- `public/` 是手机看到的网页，包含原桌宠角色素材和响应式聊天界面。
- `server.cjs` 是连接网页与桌宠的桥梁，运行于原有 Electron 主进程；请求交给已经创建的 `agent.controller`，并实时更新网页。AI 关闭时报错，Agent 关闭时使用原有普通聊天功能。
- 浏览器通过长轮询接收逐步回复，避免 Quick Tunnel 不支持 SSE 的问题。网络暂断会自动重连；重连后恢复电脑端仍在运行的任务状态。
- `install.py` 向原 `main.js` 添加桥梁启动入口，并通过 `desktop_patch.py` 为 preload 和编译后的桌面聊天界面添加受限的共享会话 IPC。补丁检查唯一标记，遇到不兼容版本会停止，不盲目替换。首次原始 ASAR 备份在 `backups/app.original.asar`；每次安装还会按当前包的 SHA256 保存 `backups/app.before-remote-<SHA256>.asar`，用于恢复本次更新前的版本。安装时验证备份、补丁完整性、重复执行一致性及重建文件内容；可先运行 `python remote-chat/install.py --check`，只检查不安装。`resources/app.asar.new` 保留原样，运行旧“更新桌宠.bat”会覆盖入口，更新后需重新检查并运行安装脚本。
- `server.test.cjs` 使用模拟 Agent 验证权限和会话协议；真实模型与浏览器验收另见 `VALIDATION.md`。
- 运行数据在 `%APPDATA%\chibi-desktop-pet\remote-chat`。`shared-history.json` 保存最近 200 条共享消息，原 `config.json` 镜像最近 40 条。第一次升级会备份并合并桌面与网页旧记录；旧桌面消息没有时间戳，保持其原顺序，再接入网页记录。`before-sync-migration.json` 保留升级前两份记录，旧 `history.json` 不覆盖。中断中的回复不做跨程序重启恢复。

## 安全措施

服务只监听本机 `127.0.0.1:17861`。Cloudflare Tunnel 是对外入口，网页走 HTTPS。严格限制允许的 Host 和 Origin，公网域名必须在电脑本地 `origins.json` 中精确列出。

随机高强度访问口令通过 scrypt 校验；口令文本仅保存于本机供主人登录，验证文件只存盐和哈希。浏览器使用有效期 12 小时的 HttpOnly、SameSite=Strict 会话 Cookie，公网 Cookie 带 Secure。修改请求须通过来源检查和 CSRF Token，错误口令最多十次后等待十分钟。登录信息不放 URL，不写浏览器 localStorage。

模型密钥只在原桌宠进程中使用，网页显示文本使用 textContent 防止脚本注入。原有 Agent 工具授权、文件夹约束和高风险确认继续生效；登录后的网页可对共享任务给出单次允许；设置页面支持名称、人格、外观、AI 开关、模型服务地址与名称、写入新 API Key、智能体开关、步骤上限和工具协议。API Key 写入后按原 ConfigStore 机制保存，已有密钥不返回网页。更换服务地址需同时提供对应的新密钥，避免旧密钥被带到新服务；仅支持 HTTPS 和本机 HTTP。不能通过网页更改全盘访问、自动允许、工具权限或插件配置。设置保存带修订号，另一端修改后旧表单不能覆盖新设置；执行任务期间不能从网页保存设置。电脑端现有权限设置（包括全盘访问和自动允许）继续有效。持有口令的人可以像主人一样请求 Agent 操作电脑，务必保护口令和本机账户。Cloudflare 作为 HTTPS 代理会处理网页及聊天流量。

换口令：退出桌宠，删除运行数据中的 `auth.json`，重新启动桌宠后会生成新口令，所有旧会话随程序退出失效。恢复原版：退出桌宠，将 `backups/app.original.asar` 复制回 `resources/app.asar`。

官方依据：[Quick Tunnel 限制](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)、[cloudflared 下载](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/)。

项目根目录新增 `打开桌宠聊天.bat` 与 `打开桌宠设置.bat`，可直接打开电脑端面板，方便不用追着移动中的角色点菜单。

## 视觉能力（2026-11-13）

已配置视觉模型 `deepseek-flash`，共用原 DeepSeek 聊天服务和密钥。电脑端可以调用现有 `analyze_screenshot` 分析屏幕；发送电脑截图给外部模型前仍需逐次确认。

网页点击输入区的“图片”，选择 PNG/JPG（最多 5 MB），填写问题并发送即可分析。图片不会执行工具指令；上传后先经过文件签名、像素上限和解码检查，再转换为 PNG，移除原文件元数据并将长边缩至最多 2048 像素。图片与分析结果保存在电脑端并同步共享会话；网页显示图片缩略图，桌面原聊天界面显示图片文件名和分析结果。后续 Agent 如需重新读图，可以使用历史附图路径调用受确认保护的分析工具。

“设置 → 视觉”可修改模型、服务地址和独立密钥。默认使用聊天密钥，独立密钥为只写输入；不允许把聊天密钥带到不同服务。清空视觉模型名称可停用视觉。

附图保存在 `%APPDATA%\chibi-desktop-pet\remote-chat\images`，访问需要登录且图片仍需属于当前共享聊天记录。图片文件会保留在本机，不自动删除；清空聊天后对应旧图无法继续通过网页接口访问。截图不进行自动或持续采集。图片分析会产生模型接口调用费用。

## 网页形象选择

在“设置 → 外观 → 桌宠形象”选择“橙发女孩”或“DeepSeek 鲸鱼妹”，查看立绘预览后保存。选择与电脑端共用 `character` 设置；网页头像、陪伴立绘、欢迎图、标签图标与配色跟随切换，另一端修改后网页自动同步。鲸鱼妹使用新版程序内已有的蓝紫鲸鱼女仆立绘，网页展示静态图片，不假装具备素材中缺失的动画。切换形象不修改名称、人格、模型或聊天记录。

网页版只接受 `orange` / `deepseek` 两个角色标识，不接收任意素材路径或外部图片地址；原来的登录、版本冲突和整份设置校验继续生效。桌面补丁通过 `dist/assets/index-*.js` 和聊天模块结构识别目标，兼容重新打包后的文件名；回复解析函数从当前代码识别，不依赖旧版压缩变量名。无法识别必要结构时安装会停止，不覆盖当前包。

## Computer Use 操作说明

已经启用，可在网页“设置 → 智能体 → 启用 Computer Use 电脑操作”关闭或开启。它沿用电脑端“界面自动化”工具组的权限，且需要开启智能体模式并配置视觉模型。此功能运行在桌宠程序内，不需要 Codex 在线代为操作。

流程是：找到唯一窗口 → 确认发送该窗口截图 → 视觉识别目标 → 确认一次操作 → 检查窗口和目标是否仍有效 → 鼠标/键盘输入 → 再截图核验结果。两端都会看到任务进度和确认卡。界面变了、窗口移位、观察过期或目标不清晰时会停止，要求重新观察。

支持点击、双击、右击、单行文字输入、按键、滚动和拖动。Computer Use 的新工具为 `computer_observe` 和 `computer_act`；旧的无障碍工具继续保留，用于可以可靠识别控件的软件。动作一次只使用一张观察，每张观察最长有效 180 秒，且只属于当前任务。不能凭空传任意坐标，必须引用视觉观察产生的目标编号。

**边界**：当前只支持主屏幕内完整显示的窗口，不操作 UAC 或安全桌面，不绕过 Windows 前台限制或权限等级。不能操作桌宠自己的聊天、设置或确认窗口；只有项目内独立测试窗口例外。截图及页面文字属于不可信数据，不是授权。每次视觉观察和动作仍逐次确认，没有自动允许模式。`type` 禁止回车、换行和 Tab；发送/提交需单独的明确按键或点击确认。未知剪贴板粘贴和任意全局切换键不通过窗口操作工具开放。

按 Win 键使用独立工具 `computer_system_key`：目前支持 `win`（开始/系统搜索）、`win+e`（资源管理器）、`win+d`（显示桌面）。每次单独确认；只按键，不自动填写搜索或运行命令。操作后按前台系统窗口身份检查结果，并使旧视觉目标全部失效。其他 Win 组合（包括 Win+R）尚未开放。

自绘列表的滚动不依赖无障碍 ScrollPattern：先用 `computer_observe` 定位消息列表、文章或内容区域，再 `computer_act` 选择 `action=scroll`，方向支持 `up/down/left/right`，每次 1～5 个滚轮刻度（默认 3）。系统滚轮设置影响实际距离，不能理解成固定像素。滚动后必须核验内容变化；到达边界不算成功。

截图现在通过真实窗口句柄选取窗口采集源，不再裁切桌面截图来冒充窗口。窗口采集失败、隐藏、最小化、位于其他虚拟桌面或采集期间前台变化时停止。当前 Electron 33 无法枚举自身窗口，只有明确允许的本地测试页面可使用自身页面采集并按客户区坐标映射；真实微信等第三方窗口没有这条回退路径。

点击“停止任务”会阻止后续步骤；已经发出的点击或输入无法自动撤销。视觉核验可能判断不准，不能保证所有软件或所有界面都成功。图片分析使用已配置视觉服务，每次动作后还会分析一次窗口截图。

双击根目录 `测试桌宠电脑操作.bat` 可打开不会连接账号、不修改个人文件的测试窗口。可以对她说：“只在桌宠电脑操作测试窗口，把计数加到 1，然后在输入框写入电脑操作测试成功，用 Computer Use 完成。”

实现位于 `computer-use/windows.cjs`（固定 Win32 输入/窗口后端）、`computer-use/tools.cjs`（观察、时效、目标检查、动作与视觉核验）、`computer-use/index.cjs`（工具注册与开关）。外部参数作为 JSON 数据传递给静态 PowerShell，不拼接成脚本。截图先在本机裁切至目标窗口，正常流程会删除用于视觉调用的临时 PNG。

依据：[Electron 屏幕采集](https://www.electronjs.org/docs/latest/api/desktop-capturer)、[Windows SendInput](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-sendinput)。

## 视觉空答和定位 JSON 失败修复

图片分析、截图分析和 Computer Use 共用 `vision-client.cjs`，Electron 通过 `vision-adapter.cjs` 接入。DeepSeek 请求关闭思考模式，输出预算从原来的 800 提高至 4096；遇到截断、空答或格式错误时，对同一张图片最多再请求一次（8192）。定位请求使用 JSON 模式并验证结果，不修补或猜测损坏的坐标。重试只读取图片，不重放点击、输入或发送动作。

现在会区分接口认证失败、超时、空答、截断、JSON 格式错误和窗口前台限制，避免统一声称“没有视觉能力”。诊断记录在 `%APPDATA%\chibi-desktop-pet\remote-chat\vision-diagnostics.jsonl`，只含服务域名、模型、状态、输出长度和 token 等元数据，不记录密钥、图片、回答正文或思考正文。截图确认和前台检查继续生效。

依据：[DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)、[接口输出与 JSON 模式](https://api-docs.deepseek.com/api/create-chat-completion/)。
